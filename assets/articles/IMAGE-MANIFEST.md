# Article image manifest

- **thumb** — 560x400 (7:5). Used in the topic page's "Everything on..." list row at 140x100. Compose tighter than the hero so the subject survives the small crop.

Both use the same prompt: the thumb is a tighter-framed variant of the same scene, not a different one.
Save each to its `output` path, then ask me to swap them in.
